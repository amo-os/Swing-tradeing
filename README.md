# Swing Trading Signal System

A research and backtesting system for Indian cash-equity swing trading.

## Current stage

Phase 0/1: project setup and market-data feasibility.

## Safety rules

- No automatic order placement.
- No real-money trading during development.
- Validate data before generating signals.
- Preserve raw source data.
- Include transaction costs and slippage in backtests.
- Do not claim profitability without out-of-sample validation.
